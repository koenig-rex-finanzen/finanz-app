# Unser Geld

Ausgelieferte Web-App (GitHub Pages) für die gemeinsamen Finanzen von Kai und Natalie.

**Hier liegen keine Daten.** Die App lädt die Excel-Datei erst nach der Microsoft-Anmeldung
direkt aus OneDrive bzw. vom Gerät. Der Quellcode liegt im privaten Repo `finanz-tool`;
diese Dateien werden von dort mit `tools/bauen.sh` erzeugt – hier nicht von Hand ändern.
